# 新航道香港项目 V1 使用说明

## 当前架构

家长通过腾讯问卷二维码填写，腾讯问卷保存原始答卷。使用者在腾讯问卷后台导出自己有权访问的 CSV，然后打开 GitHub Pages 上的公开分析工具并导入文件。网站只发布静态应用代码；CSV、评分结果及 PDF/ZIP/汇总 CSV 均由当前浏览器本地处理和生成，不会写入网站或发送到分析服务器。刷新、清空或关闭页面后，需重新导入。下载后的文件由使用者自行保存在受保护的位置。

页面不提供家长填写入口、顾问登录或集中客户存储，也不会连接腾讯问卷自动拉取答卷。正式腾讯问卷二维码由运营方在腾讯问卷后台提供。本地分析工具无需配置问卷链接。

## 本地预览

需要 Node.js 22 或以上。运行 `pnpm run build:pages` 后，双击“启动本地分析.cmd”或执行 `pnpm run start`，访问 `http://127.0.0.1:4180/`。根地址预览 GitHub Pages 的静态构建产物；`http://127.0.0.1:4180/local-tool/index.html` 是本地源文件预览。结束后关闭启动窗口。页面只绑定本机地址。

## 腾讯问卷导出与导入

1. 在腾讯问卷后台选择本次问卷的答卷，导出 CSV，并存放在本机受保护的文件夹。
2. 在分析工具选中 CSV。当前实际样本使用 UTF-8 BOM；如果其他批次中文乱码，可选 GB18030 后重新导入。
3. 工具会依据实际题名、题号前缀和腾讯元数据列自动匹配字段。打开“CSV字段映射”检查，不能确认的列请手动指定；不要按列顺序猜测。
4. 点击“确认映射并评分”。评分完成后可按等级筛选，点“详情”检查每项答案、得分、规则、待核实原因及建议。

已核对的腾讯导出样本格式、字段映射和限制见 [TENCENT-V1.md](TENCENT-V1.md)。目前兼容验证基于 2026-10-10 导出的三份虚构测试答卷。不同问卷设置或导出选项可能改变 CSV 列，应以每次平台实际文件为准。

## 评分与导出

评分规则文件为 `local-tool/rules-v1.json`，版本 `v1.0.0`。分值、等级阈值、缺失答案和待核实规则见 [SCORING-V1.md](SCORING-V1.md)。本轮未修改规则或 PDF 结构。评分只用于初步需求匹配和跟进优先级，不代表录取、身份审批或成交概率。

详情页点击“下载本客户PDF”生成单份报告。“下载当前筛选PDF ZIP”按当前筛选导出，每批最多 200 人，ZIP 同时包含逐客户 PDF 与汇总 CSV。也可以单独下载筛选后的汇总 CSV；公式前缀会转义，CSV 带 UTF-8 BOM。报告使用浏览器本机中文字体绘制为图像页，内容不可搜索或复制。

## 数据边界

导入文件只保存在当前页面内存中；应用没有上传、外部 AI、云数据库或浏览器持久存储调用。静态页面的内容安全策略禁止网络连接；本地服务只接受来自 `127.0.0.1` 的 GET 请求。公开构建只打包静态应用文件和虚构演示资料，不包含腾讯导出文件、客户联系方式、PDF或ZIP。`.gitignore` 屏蔽 CSV、Excel、PDF、ZIP、data 与 `.env`；忽略规则不能替代发布前的 Git 内容检查。

下载文件不加密。请仅导入获授权的答卷，完成后清空页面，并把导出文件存放在有访问控制的电脑位置。刷新页面不会保留当前客户。

## 本地检查

`pnpm test` 运行解析、评分、PDF/ZIP、公式注入防护和静态构建边界测试；`pnpm run build:pages` 生成供 Pages 使用的 `dist`。本地验收结果与截图见 [TEST-REPORT-V1.md](TEST-REPORT-V1.md)。GitHub Pages 工作流仍是手动触发；本阶段未推送或发布。
